# اپلیکیشن اندروید عیب‌یابی اتاق برق

## پیش‌نیاز
- Android Studio Ladybug یا جدیدتر
- JDK 17
- بک‌اند در حال اجرا روی پورت 5000

## باز کردن پروژه
1. Android Studio را باز کن
2. Open → پوشه `electrical-android` را انتخاب کن
3. صبر کن تا Gradle Sync تمام شود

## تنظیم آدرس سرور
فایل زیر را باز کن و IP را تغییر بده:

`app/src/main/java/com/electrical/troubleshoot/util/Constants.kt`

- شبیه‌ساز: `http://10.0.2.2:5000/api/`
- گوشی واقعی (همان شبکه): `http://IP_کامپیوتر:5000/api/`

## اجرای اپ
- روی شبیه‌ساز یا گوشی Run بزن
- ورود با: admin / admin123

## صفحات آماده
1. ورود
2. لیست ۲۱ اتاق برق (با جستجو)
3. لیست مکانیزم‌های هر اتاق
4. شروع عیب‌یابی + چک‌لیست مرحله‌ای با دکمه‌های بزرگ
5. لیست تجربیات

## ویژگی‌های بعدی که می‌توان اضافه کرد
- نمایش PDF نقشه داخل صفحه عیب‌یابی (با هایلایت نقطه)
- استخراج خودکار نام اتاق از متن PDFهای EPLAN
- حالت آفلاین کامل با Room
- ساخت SOP از روی جلسه

## نام اتاق از EPLAN
به جای نام‌گذاری دستی:
- هنگام آپلود PDF، بک‌اند می‌تواند متن صفحه اول را استخراج کند
- نام اتاق / تابلو از Title Block پیشنهاد داده می‌شود
- این بخش در نسخه بعدی اضافه می‌شود
